# fresh

A clean workspace. Work in this folder is independent of the rest of the
repository: nothing outside `fresh/` is used as context here.

## Working preferences
- The book is still being drafted. Focus on narrative (story, character, theme, structure), not continuity
  or logistics (dates, page counts, timelines). Save line editing for later.
- Use American English, except in dialogue from British characters.
- **Align before rewriting.** Don't turn feedback straight into a rewrite. Discuss each change first and agree on
  what it should be, then make it. No revise-and-resend loops without coordination.
